# Map & Geolocation App 🗺️

Адаптивное веб-приложение с интерактивной картой, геолокацией и поиском адресов, для колледжа.

## 🚀 Функционал
- **Интерактивная карта:** Построение на базе Leaflet.js и Esri тайлов с фокусом на Колледж Ала-Тоо (мкр. Тунгуч).
- **Локации района:** Список объектов рядом с вашим местоположением с рейтингом и автоматической прорисовкой маршрута (полилиний).
- **Живой поиск:** Интеграция с Nominatim API для поиска адресов и мгновенной навигации.
- **Адаптивный дизайн:** Точное повторение макета Figma (шапка, выпадающее меню, нижняя карточка Bottom Sheet).

## 🛠️ Стек технологий
- HTML5, CSS3, JavaScript (ES6+)
- Leaflet.js (v1.9.4)
- Esri World Street Map
- Nominatim API
