# Map & Geolocation App 🗺️

Веб-приложение с интерактивной картой Бишкека, геолокацией и поиском адресов, созданное по макету из Figma для колледжа.

## 🚀 Функционал
- Интерактивная карта на базе **Leaflet.js** и **OpenStreetMap**.
- Готовые локации Бишкека с построением маршрутов.
- Живой поиск адресов через **Nominatim API**.
- Адаптивный интерфейс для ПК и смартфонов.

## 🛠️ Технологии
HTML5, CSS3, JavaScript, Leaflet.js, OpenStreetMap, Nominatim API.

## 📦 Запуск
1. Скачайте репозиторий или откройте сайт по [ссылке на GitHub Pages](https://kurmanbek2.github.io/Map-Geolocation-App-with-API-Integration/).
2. Для локального запуска просто откройте файл **`index.html`** в любом браузере.
